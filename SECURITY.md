# Security Policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue or discussion.

Email **support@musclog.app** with:

- what you found and where (screen, file or feature)
- the app version and platform (Android, iOS or web)
- steps to reproduce, or a proof of concept if you have one

Please do not include real personal data (workouts, food logs, body metrics, cycle records) in a report.

## Scope

Musclog stores its data on your device and has no Musclog account or server holding user data, so the most relevant reports concern the app itself: local data storage and encryption, backup and restore, the optical (QR) transfer, imports of untrusted files or links, and the public website.

## Supported versions

Fixes go into the latest release. Please check that the problem exists in the [latest release](https://github.com/blopa/musclog-app/releases/latest) before reporting.
